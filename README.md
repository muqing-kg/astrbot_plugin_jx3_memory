# 剑网3数据库

AstrBot 插件。把剑网3 的物品、任务、成就、心法、副本、黑话整理成一份本地记忆库，聊天里提到这些东西时，把对应的正确含义递给模型，让它接得住话，而不是编一个不存在的词。

## 它是怎么工作的

插件只挂一个大模型请求钩子，不注册消息监听、不发消息、不抢回复。

- 每次模型要回话前，拿当前消息和最近几条历史去碰词表，**碰到了才注入**，碰不到一个字都不加。
- 注入内容是「名字 + 一句摘要」，以第一人称记忆的口吻写在当轮请求里，随请求结束丢弃，不进对话历史，也不改系统提示词。
- 句子里出现「怎么」「在哪」「攻略」这类问法时，命中的第一条会额外带一段正文（攻略步骤、任务流程、奇遇触发），最多 400 字。
- 同一会话连续几轮命中同一批条目时不重复注入；换了话题、命中集合变了才重新给。
- 匹配是字面的，不用向量：塞错资料比不塞更糟。

## 安装

在 AstrBot 的插件管理里填仓库地址安装：

```
https://github.com/muqing-kg/astrbot_plugin_jx3_memory
```

或者把整个目录放进 `data/plugins/`。需要 AstrBot 4.29 及以上，无第三方依赖。

数据库跟着仓库一起下发，装完即用，不需要另外下载或构建。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `proxy` | 空 | 抓公告用的代理，留空直连，形如 `http://127.0.0.1:7890` |
| `db_path` | 空 | 记忆库路径，留空用插件目录下的 `data/memory.sqlite3` |
| `max_items` | 5 | 单轮最多注入几条 |
| `max_chars` | 1200 | 单轮注入字数上限 |
| `recent_messages` | 3 | 匹配时一并参考最近几条历史，设为 0 只看当前消息 |

命中的条目越多越容易带偏话题，`max_items` 一般 3 到 5 条就够。`recent_messages` 是给「这个呢」「那个怎么打」这类短句用的，让它们能定位到上一轮说过的东西。

### 更新

公告每天凌晨 3 点自动同步一次，拉最新 50 条，按公告 id 去重，正文变了才更新，正文没变只刷新抓取时间。同步失败只记日志，不影响注入。

物品、任务、成就等大件数据是构建时的快照，不随插件运行更新。

## 已知限制

- 库里查不到的东西，插件什么都不加，模型会用「记不太清了」这类话带过，不会硬编。
- 物品、任务、成就里的两字名不进词表：「长安」「龙渊」这类既是地名也是任务名，注进去比不给更糟。「玄晶」这类常用两字名走别名白名单放行。
- 外观、坐骑、家具、书籍、声望没有独立数据源，只能从物品库的外观名、分类与获取途径字段里取。
- 攻略与公告按发布时间取，过期的说法可能与当前版本不符。
- 只覆盖重制版，不含缘起。
- 库跟着仓库走，更新数据要重新拉一次仓库。
