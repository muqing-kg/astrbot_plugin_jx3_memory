# astrbot_plugin_jx3_memory

AstrBot 插件：把剑网3 的游戏知识做成常驻记忆，每一轮对话都注入，让模型随口就能说对，而不是被问到才去查。

与 `astrbot_plugin_jx3_news_kb`（剑网3活动提醒）是两个独立插件，互不依赖：

| | 活动提醒 | 本项目 |
|---|---|---|
| 职责 | 抓公告 → 抽活动 → 到点发提醒 | 建知识库 → 每轮注入 |
| 触达方式 | 主动推送消息 | 不改消息，只在 LLM 请求里加料 |
| 数据 | 公告、活动、提醒 | 物品、任务、成就、通识、攻略 |

## 文档

- `docs/数据源.md`：jx3box 与 JX3API 的接口实测清单（端点、分页、字段、量级、坑）
- `docs/设计.md`：三层记忆结构、存储、检索、注入与同步策略
- `TODO.md`：分阶段任务
- `.memory/state.md`：当前进度，开工先读这个

## 硬约束

- 插件只挂 `on_llm_request` 钩子，不注册消息监听、不调 `stop_event`，不与提醒插件抢消息。
- 库体积上限 1GB，超过就先砍低价值数据，不加机器资源。
- 回复中不向用户展示代码。
