# 数据源实测清单

所有结论来自 2026-11-24 的实际请求，不是文档转述。域名、路径、字段名照抄即可用。

## 一、jx3box（游戏百科与数据库）

`www.jx3box.com` 是 Vue 单页应用：直接抓 HTML 只能拿到空壳，`/wiki/static/...` 会被 302 回 SPA，`robots.txt` 与 `sitemap.xml` 也返回 SPA 页面，没有站点地图。数据只能走 API。

### 1. 物品与成就、任务（node.jx3box.com）

| 端点 | 说明 |
|---|---|
| `GET /api/node/item/count` | `total` 261682；`quality_4` 202593 |
| `GET /api/node/item/list?page=&per=` | `per=100` 时单页 80,885 字节、1.5 秒；返回 `{current_page, data, total}` |
| `GET /api/node/item/{id}` | 单条详情 |
| `GET /api/node/item_merged/id/{ids}`、`/api/node/item_merged/name/{name}` | 批量／按名查 |
| `GET /api/node/item/search`、`/api/node/item/newest`、`/api/node/item/menus`、`/api/node/item/menu_list` | 搜索、最新、分类树 |
| `GET /api/node/achievement/count` | `general` 7877、`armor` 621，合计 8498 |
| `GET /api/node/achievement/list?page=&per=` | 单条含 `ID/Name/Desc/Point/General/Sub/IconID/SubAchievements` |
| `GET /api/node/quest/category` | 330 个分类，各类 `total` 求和 20114 |

### 3. 静态映射（github.com/JX3BOX）

- `jx3box-data` 仓库 6.9MB，`data/` 下有 `xf`（心法）、`server`、`app`、`fb`（副本）、`martial`、`desert`、`serendipity`（奇遇）、`product`、`role`，另有 `raw/std`、`raw/origin`。内容是 ID／图标／名称映射，没有正文，适合直接 clone 当字典表。

## 二、JX3API（公告）

| 项目 | 值 |
|---|---|
| 列表 | `GET https://www.jx3api.com/news/records?limit=N` |
| 信封 | 顶层 `{status, detail}`，不是 `{code, data}` |
| limit | 只认 1～50，`page` 参数被忽略 |
| 单条字段 | `catid`、`title`、`type`、`url`、`date`（`YYYY/MM/DD`）、`desc{asktime, inputtime, content（HTML）, title}` |

`desc.asktime` 有空值，`inputtime` 是 unix 秒，正文在 `desc.content` 且为 HTML。取数时按 `inputtime → asktime → date` 兜底。

实时推送：`wss://socket.nicemoe.cn/`，报文 `{action, detail}`，时间戳为秒。`action=2002` 是官方资讯，`detail` 只有 `{date（MM/DD）, title, type, url}`，**没有正文**，收到后必须自己按 `url` 抓正文。服务端不收订阅握手，连上就推；无正式文档，属实测结论。

## 四、坑

- 先取 `count` 再决定是否全量抓，别按"页数未知"盲刷。
- 单页体积可达 80KB，2617 页约 200MB 原始 JSON，落盘前先压缩字段。
- 没有公开的速率限制说明。默认 2～3 并发、错误退避，别用满。
- 社区文章的正文在 `post_meta` 里，可能夹带图片与外部链接，入库前清洗。
- 任务文本覆盖主线与支线对白；CG 文案、配音台词、完整小说式剧情该源没有，别指望。
